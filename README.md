## Админка

Доступна по адресу `/admin`. Защищена Basic Auth.

**Переменные окружения для админки:**
- `ADMIN_USER` — логин (по умолчанию `admin`)
- `ADMIN_PASS` — пароль (**обязательно задайте!**)

Если `ADMIN_PASS` пустой — админка **открыта без пароля**.

**Что есть в админке:**
- 📊 Статистика: всего / успешно / ошибок / сегодня
- 📋 Последние 100 пересылок (фильтр по статусу)
- 👁️ Детали каждой пересылки
- 🚫 Чёрный список (mid, которые больше не пересылать)
- ⚙️ Просмотр настроек (группы, канал, фильтры)
- 🧹 Очистка истории старше 90 дней
- 🔗 Кнопка перерегистрации вебхука

**Дополнительные эндпоинты:**
- `/admin` — главная
- `/admin?status=success` — только успешные
- `/admin?status=error` — только ошибки
- `/admin/repost/<mid>` — детали
- `/admin/blacklist` — чёрный список
- `/admin/settings` — настройки
- `/debug` — быстрый статус без авторизации
- `/health` — JSON
