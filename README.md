# max-reposter-debug

Промежуточный проект для перехвата JSON вебхуков от MAX.

## Зачем

Нужно узнать точную структуру `message.body.attachments`, чтобы написать
скачивание медиа для репостера.

## Переменные окружения (Bothost)

| Переменная | Обязательно | Пример | Описание |
|---|---|---|---|
| `MAX_TOKEN` | да | `abc123...` | Токен бота MAX |
| `PUBLIC_URL` | да | `https://maxbot.bothost.tech` | Публичный URL бота |
| `PORT` | нет | `3000` | Порт (Bothost задаёт сам) |

## Что делать

1. Создать репозиторий на GitHub.
2. Залить эти 4 файла.
3. В Bothost создать проект, подключить репозиторий, выставить переменные.
4. Дождаться деплоя.
5. Открыть `https://<домен>/debug`.
6. Нажать «🔗 Настроить вебхук».
7. В группе MAX (где бот — админ) отправить:
   - текстовое сообщение
   - фото (одно)
   - фото (альбом из 3 штук)
   - видео (mp4)
8. Обновить `/debug` — увидеть пойманные JSON.
9. Нажать «📥 Скачать все JSON одним файлом».
10. Прислать файл для написания `media_downloader.py`.

## Эндпоинты

- `/` — редирект на `/debug`
- `/webhook` — принимает события от MAX (POST)
- `/debug` — UI со списком пойманных вебхуков
- `/view/<file>` — просмотр одного вебхука
- `/download/<file>` — скачать один вебхук
- `/download_all` — скачать все одним файлом
- `/clear` — удалить все пойманные вебхуки
- `/setup_webhook` — перерегистрировать вебхук в MAX
- `/health` — health-check
